## 2. 后端项目

- **基础框架**：Spring Boot 3.5.16 + Java 21
- **ORM**：MyBatis Plus 3.5.17
- **基础包**：`com.yupi.codertestbackend`

### 2.1 实体类（Entity）

共有 3 个数据库实体，均使用 `@Data`（Lombok）、`@TableName`、`@TableLogic` 逻辑删除。

#### User.java — 用户实体

```java
@Data
@TableName("user")
public class User {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String username;       // 登录账号
    private String password;       // 登录密码（MD5 加密）
    private String nickname;       // 用户昵称
    private String avatar;         // 头像 URL
    private Integer salary = 10000; // 薪资，用于动态调整关卡难度
    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    @TableLogic
    private Integer isDelete;      // 逻辑删除
}
```

#### Level.java — 关卡实体

```java
@Data
@TableName("level")
public class Level {
    private Long id;
    private String levelName;       // 关卡名称
    private String levelDesc;       // AI 生成的需求描述
    private String options;         // 全部选项（JSON 数组，10+ 个）
    private String trueOptions;     // 正确选项（JSON 数组）
    private String difficulty;      // 难度：简单 / 中等 / 困难
    private Integer targetSalary;   // 目标薪资
    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    private Integer isDelete;
}
```

#### UserLevel.java — 用户关卡实体（闯关记录）

```java
@Data
@TableName("user_level")
public class UserLevel {
    private Long id;
    private Long userId;
    private Long levelId;
    private String userOptions;      // 用户选择的选项（JSON）
    private Integer score;           // AI 评分 0-100
    private String comment;          // 幽默评价
    private Integer salaryChange;    // 薪资调整（正数增加，负数减少）
    private String suggest;          // 公司投递建议
    private String reason;           // 评分原因
    private String trueOptions;      // 正确答案（JSON）
    private String standardAnswer;   // 标准答案解析（Markdown）
    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    private Integer isDelete;
}
```

### 2.2 AI 模型（DTO，非数据库实体）

- **GeneratedLevel.java** — AI 生成的关卡内容（levelName, levelDesc, options, trueOptions, difficulty, targetSalary）
- **EvaluationResult.java** — AI 评估结果（score, comment, salaryChange, suggest, reason, standardAnswer）

### 2.4 请求 DTO

- **UserLoginRequest** — username, password
- **UserRegisterRequest** — username, password, checkPassword, nickname

### 2.5 控制器（Controller）

| 控制器 | 路径前缀 | 接口 |
|--------|----------|------|
| UserController | `/user` | `POST /register` 注册<br>`POST /login` 登录（存 session）<br>`POST /logout` 登出<br>`GET /current` 获取当前用户 |
| LevelController | `/level` | `POST /generate` AI 生成关卡<br>`GET /detail?id=X` 查询关卡详情 |
| UserLevelController | `/user-level` | `POST /submit` 提交答案（AI 评估）<br>`GET /get?id=X` 查询单条记录<br>`GET /list` 分页查询闯关记录 |

### 2.6 Mapper 接口

所有接口继承 `BaseMapper<T>`，无自定义方法，通过 `MybatisPlusConfig` 中 `@MapperScan` 扫描：

- **UserMapper** extends `BaseMapper<User>`
- **LevelMapper** extends `BaseMapper<Level>`
- **UserLevelMapper** extends `BaseMapper<UserLevel>`

### 2.7 Service 层

| 接口 | 实现 | 核心功能 |
|------|------|----------|
| UserService | UserServiceImpl | 注册（MD5 加密 + 随机默认头像）、登录、获取当前用户 |
| LevelService | LevelServiceImpl | AI 生成关卡，根据薪资定难度，随机选技术栈和题型 |
| UserLevelService | UserLevelServiceImpl | AI 评估答案，计算分数和薪资变动，更新用户薪资 |

### 2.8 AI Service（LangChain4j）

- **LevelGenerationAiService** — 使用提示词 `prompts/level-generation-system-prompt.txt` 生成关卡
- **ResultEvaluationAiService** — 使用提示词 `prompts/result-evaluation-system-prompt.txt` 评估答案
- **AiConfig** — 配置 `QwenChatModel`，通过 `AiServices.create()` 创建 AI Service Bean
- 使用阿里云 DashScope（百炼），模型 `qwen-max`

### 2.9 公共类（common）

- **BaseResponse** — 统一响应体（code, message, data）
- **ResultUtils** — 快捷构建成功响应
- **ErrorCode** — 错误码枚举（PARAMS_ERROR, USER_EXIST, USER_NOT_FOUND, PASSWORD_ERROR, NOT_LOGIN）
- **GlobalExceptionHandler** — `@RestControllerAdvice` 全局异常处理

### 3.4 API 接口封装

所有 API 函数在 `src/api/index.js` 中定义，通过 `src/api/request.js`（Axios 实例）发送请求。

响应拦截器处理逻辑：
- `code === 40100`（未登录）→ 清除本地登录态 + 跳转登录页
- `code !== 0` → 抛出异常（含 message）

```javascript
// 用户接口
register(data)           // POST /user/register
login(data)              // POST /user/login
logout()                 // POST /user/logout
getCurrentUser()         // GET /user/current

// 关卡接口
generateLevel(salary)    // POST /level/generate
getLevelDetail(id)       // GET /level/detail

// 闯关接口
submitLevel(data)        // POST /user-level/submit
getUserLevelDetail(id)   // GET /user-level/get
listUserLevels(params)   // GET /user-level/list
```

### 3.5 数据流向

```
用户操作 → Vue 组件 → Pinia Store → API 函数 → Axios → /api/* → Spring Boot Controller → Service → Mapper → MySQL
                                                                                    ↘
                                                                              LangChain4j AI
```

登录态通过 **HttpSession + Cookie** 维护，前端 `withCredentials: true` 自动携带。
