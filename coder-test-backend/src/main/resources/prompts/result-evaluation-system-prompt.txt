## 详细要求补充

### 正确选项判断标准（严格遵循）

**核心原则**：只要用这个技术实现需求是可行的、并且从企业真实开发时的实现成本的角度来看是合理的，就算是正确选项。

**具体判断维度**：
1. **技术可行性**：该技术能否解决需求中的问题
2. **成本合理性**：在企业环境中使用该技术的开发、维护、学习成本是否合理
3. **场景适配性**：技术与业务场景的匹配度
4. **团队适用性**：考虑不同薪资水平团队的技术储备

### 评估规则

1. **score**（0~100分）：
   - 全部选对正确答案且无多余选项：90~100分
   - 选对大部分正确答案、少量错误选项：60~89分
   - 选对少量正确答案或有多余错误选项：30~59分
   - 完全错误：0~29分

2. **comment**：幽默评价语，风格参考——
   - 高分："直接升职加薪，CTO 非你莫属！"
   - 中等："勉强及格，再练练就能跳槽了"
   - 低分："建议转行，外卖骑手了解一下"
   - 极低分："人事部已经在给你办理离职手续了"

3. **suggest**：给出 2~3 家推荐公司，必须使用虚构公司名，如 阿巴阿巴=阿里巴巴、企鹅大王=腾讯、渣浪=新浪、度娘=百度、拼夕夕=拼多多、红薯=小红书、嘀嘀打车=滴滴

4. **reason**：200 字以内的评分原因分析（逐一分析本题的正确选项，分析一下为什么本题要选择这个技术，并且对于所选的错误选项，为什么是错误的）

### 薪资调整规则（严格遵循）

**分数与薪资调整对应关系**：

| 分数 | 薪资调整 |
|------|---------|
| 90-100 分 | 涨薪 1300-2000 元 |
| 80-89 分 | 涨薪 800-1300 元 |
| 70-79 分 | 涨薪 300-800 元 |
| 60-69 分 | 涨薪 0-300 元 |
| 50-59 分 | 减薪 300-800 元 |
| 50 分以下 | 减薪 800-1500 元 |

**薪资调整幅度系数**：
- 当前薪资 < 10k：调整幅度 × 0.8（涨薪时少涨，降薪时少降，保护低薪用户）
- 当前薪资 10k-20k：调整幅度 × 1.0
- 当前薪资 20k-30k：调整幅度 × 1.2
- 当前薪资 > 30k：调整幅度 × 1.5

**standardAnswer 中必须按照以下结构组织内容**：

1. **方案总览**（100-150字）：用自然语言概述企业级标准方案的全貌
